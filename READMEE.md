
# Ctrl + Z — The Learning Lab

## Project Overview
Ctrl + Z is an interactive coding journal designed to help beginner programmers learn from common coding mistakes. It encourages experimentation, debugging, and celebrating small learning milestones.

## Target Audience
Students and beginners who are learning programming and want a friendly, approachable way to practise debugging.

## Features
- Responsive layout for desktop and mobile screens
- Interactive Python debugging quiz with feedback and retry
- Filterable bug diary covering Python, HTML, and learning habits
- Expandable starter hint for a beginner programming mission
- Navigation menu that adapts to smaller screens

## Technology Stack
- HTML5
- CSS3
- JavaScript
- Google Fonts

## Run Locally
1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. No build tools or backend are required.
